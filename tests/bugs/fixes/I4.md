# I4 - symbol pages lost their Keywords (fixed)

Patch: `patches/I4-symbol-page-keywords.diff` (`MarkdownToNotebook.wl`, `symbolNotebook`). It applies on
its own to the original file and together with the I1 patch. Backup: `MarkdownToNotebook.wl.orig-2026-10-22`.

## Change

`symbolNotebook` now calls `nb = fillDocList[nb, "Keywords", asList @ Lookup[meta, "Keywords", {}]];`.
This is the same call `guideNotebook`, `tutorialNotebook` and `overviewNotebook` make. It goes before the
step that strips unfilled `XXXX` placeholders, which until now dropped the template's Keywords placeholder.
The page gets one `Keywords` cell per front-matter entry, inside the template's closed Keywords group.

## Verification

Scripts are in `fixes/scratch-I/I4/`. `build-pages.wls` builds three pages in a fresh kernel with each
converter version, and `compare.wls` and `diffsym*.wls` compare them:
- the symbol page, `docs/MazeWalkTime.md`;
- the guide, `docs/DocPageExamples.md`;
- a scratch tutorial (TechNote), `I4/ParsingMazesTutorial.md`, since no TechNote example ships.

The converters were the original and "original + I4 only" (`scratch-I/MarkdownToNotebook.wl.I4only`).

- `symbol-keywords.wls` logic, pointed at the scratch output: Keywords cells went from `{}` to
  `{maze, walking time, shortest path, quantity, units}`.
- Symbol page: 141 -> 146 cells, the only change being +5 Keywords cells. The `KeywordsSection` now heads
  a closed group, the same shape as the guide page. After collapsing that group, the page equals the
  original exactly (`True`).
- Guide: 60 -> 60 cells, same Keywords, identical apart from IDs.
- Tutorial: 28 -> 28 cells, same Keywords, identical apart from IDs.
- Full paclet rebuild (`scratch-I/final`, DocumentationBuild included): the built
  `ReferencePages/Symbols/MazeWalkTime.nb` page metadata changes from `"keywords" -> {}` to
  `"keywords" -> {"maze", "walking time", "shortest path", "quantity", "units"}`. That is what the
  Documentation Center search uses.
- `tests.wls`: 174/174 pass with the fixed converter (and with the original).

## Limits / open points

- Only the symbol-page builder was changed. The other reference subtypes already emit Keywords through
  `docMetaCells`.
- `MANIFEST.sha256` no longer matches `MarkdownToNotebook.wl`.
