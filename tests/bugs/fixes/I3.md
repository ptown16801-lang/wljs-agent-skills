## Changes

1. Initialization: "The eight single-qubit gates" is now "The seven single-qubit gates" (I, H, X, Y, Z, S, T).
2. Snapshot H, X, Z: the text now describes what the code draws. H takes |0> to |+> at +x, X leaves |+>
   in place, and Z sends it to |-> at -x. The trajectory joins these points with straight chords, and
   the last one runs through the centre of the sphere. I changed the wording rather than the code, so
   the picture is unchanged.
3. Snapshot T, T, T: starting from |+>, two T gates reach the point a single S would, +y (T^2 = S). The
   third T turns the state a further pi/4, to (-1/Sqrt[2], 1/Sqrt[2], 0).
4. Snapshot Y: Y is a pi-rotation about y, not "flips across the x axis". Y|+> = -i|->, which is |->
   up to a global phase, so the Bloch vector moves to the opposite point, (-1, 0, 0). The old text said
   "-|+>, same Bloch point".
5. Consistency, beyond the four listed errors:
   - The Details paragraph said the red line shows "how it got there". It now says the line joins the
     states before and after each gate with straight segments, which are chords of each gate's
     circular arc, not the arc itself.
   - The front-matter `SubmissionNotes` is reworded the same way.
