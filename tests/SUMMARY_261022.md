# 70 Wolfram agent skills on WLJS: test results (22 Oct 2026)

Every skill in `~/.claude/skills/` (generated by `build.mjs`) runs on the **WLJS notebook engine** by default and puts its
result in a **WLJS notebook**. This page summarises how they were tested and what was found. The per-skill table is
`tests/RESULTS.md`; each skill's own status line says the same, both generated from the evidence.

## How each skill was tested

- **Level B — skill invocation.** A fresh Claude agent got an ordinary user request built on Wolfram's own example
  material (Mathematica `ExampleData`, the System Modeler libraries, the Wolfram Institute plugin and MarkdownToNotebook
  examples) and handled it with the installed skills. Graded on six checks: right skill, right engine, rules kept, WLJS
  notebook, correct result, clean run. Results were re-checked by hand (fresh offline kernels, independent Python).
- **Level C — independent review.** Separate reviewer agents (A–H) re-checked every graded run against its files,
  session record and window captures, re-ran key values, and could overturn any grade. Overturns were re-run, not argued.
- **Fix loop.** Each overturn led to a fix in the skill notes, `ROUTES.md`, a card or the test brief, then a re-run.
- **Owner rules held throughout:** nothing contacted Wolfram's servers (`$AllowInternet = False`, fresh kernels inside
  a network namespace; verified with `strace`), nothing was installed or published, every window on the second monitor.

## Fixes made to the integration (selection)

- WLJS: windows and dialogs on the second monitor, WebGL re-enabled for 3D, false save dialog removed, graphics kept by
  kernel-side saves.
- System Modeler visuals viewable without the System Modeler app: diagrams and icons rendered by System Modeler's
  own renderer in a fresh kernel, stored plots redrawn with `SystemModelPlot`, 3D animations replayed in WLJS
  (`Graphics3D` + slider from exported positions), control panels rebuilt as WLJS `Manipulate`s that re-simulate.
  All four annotate skills were re-run this way, the visuals were looked at, and independent reviewers re-rendered
  and re-simulated them.
- Tools: `md2wln.py` (Markdown to WLJS notebook), `capture-wljs-windows.sh` + `xcapture.py` (see a window without
  opening anything), `check-wljs-monitor.sh`.
- Skill notes: hard stops for approval steps, literature check before calling a result new, debugging helpers instead
  of global toggles, plot checks, shared-kernel rules (one System Modeler namespace, no `Begin`/`End`), offline routes.

## A side result: the Sidon theorem

The paper skill's agent proved that a counting bound for Sidon sets in Z_n fails infinitely often. The proof was
checked independently and is correct, but a literature search found it is already published (Buratti–Stinson 2021,
Corollary 3.9). The paper skills now require a literature check before presenting a result as new.
